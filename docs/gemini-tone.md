# Gemini 톤 변환(어투 변환) 연결

AI 도구의 '톤 변환'은 번역과 **같은 엔진**을 쓴다: `Vue 앱 → 프록시 → Gemini API`, 프록시는 번역과 같은
서버다(`/api/translate` 옆에 `/api/tone`). Gemini 키는 프록시에만 있고 `VITE_TONE_URL`에는 공개 주소만 넣는다.
키 하나로 번역·맞춤법 검사·모듈 조합 추천·톤 변환이 다 돌고, 무료 한도(하루 요청 수)도 같이 쓴다.

## 무엇을 하나

다 쓴 글의 **어투만** 바꾼다. 내용·정보·서식은 그대로다.

| 어투 | 기준 |
|---|---|
| 격식 있게 | 공식 안내문처럼 정중하게 — "~합니다/~드립니다", 구어체·이모지 제거 |
| 친근하게 | 가까운 사람에게 말하듯 — "~해요/~해 보세요", 쉬운 말. 반말은 안 씀 |
| 간결하게 | 군더더기를 덜어 짧게 — 정보는 하나도 빼지 않음 |

흐름은 번역과 맞춤법 검사를 합친 것이다.

- 값 모으기·보내기·적용은 **번역과 같다** — 리치 텍스트는 속성을 뗀 뼈대 HTML로 보내고, 돌아온 뼈대가
  원문과 같은지 검증한 뒤 속성을 되붙이므로 굵게·색상·링크가 그대로 남는다(`scripts/translate-core.mjs`의
  `rewriteAll`, 프런트 `applyTranslationChanges`).
- 화면은 **맞춤법 검사와 같다** — 바뀐 글마다 카드 하나, 적용 여부를 체크하고 고른 것만 넣는다. 바뀐 글은
  고쳐서 넣을 수 있다(번역 카드와 같다).
- 서버가 원문 그대로 돌려준 항목(짧은 버튼 글귀, 이미 그 어투인 글)은 카드로 보여 주지 않는다.
- 항목마다 언어가 달라도 된다 — 언어는 바꾸지 않고 그 언어 안에서 어투만 바꾼다(번역한 뉴스레터도 다듬는다).
- 전시 분야는 **보내지 않는다**. 실측(2026-10-16)에서 분야 '법률'을 힌트로 주자 뷰티 행사 글을 "법률 및 규제
  동향"으로 내용까지 바꿨다. 어투 변환에 업계 맥락은 득보다 실이 크다. 대신 프롬프트에 "주제·대상·사실을 바꾸지
  않는다"를 못 박았다.

## 한도와 전송량

번역과 같다 — 한 편을 3,000자 안팎 묶음으로 나눠 **동시에** 보내므로 한 편 = 요청 2~3회, 10초 안팎.
뼈대가 어긋난 항목은 단독으로 한 번 더 묻고, 그래도 안 되면 502로 알린다(틀린 서식은 넣지 않는다).

## 로컬 실행·배포

번역과 같다(docs/gemini-translate.md). 프록시 코드가 바뀌었으니 로컬은 `npm run proxy:translate`를 다시 켜고,
배포본은 `npm run deploy:translate`로 Worker를 다시 올린다. `.env.production`의 `VITE_TONE_URL`은 Worker 주소 + `/api/tone`이다.
